## Оценка GO/NO-GO

Термин `GO-код` означает, что маршрут и контролы присутствуют; **это не знак приемки 1:1**.

| Раздел | Статус | Подтверждено в коде | Что необходимо проверить/исправить |
|---|---|---|---|
| Общие меню, поиск, шапка, мобильный drawer | GO-код | `App.vue`, collapse, mobile overlay, topbar search | Геометрия и поведение на 375/768/1280/1440, активные группы меню, 1:1 SVG, оба theme |
| Главная | GO-код | `OverviewView.vue`, сводка и переходы | Верстка, корректность реальных сумм, мобильные таблицы |

## Очередность без повторного переписывания

1. **Блокер CI:** устранить stale проверки, типизацию и сборку; зеленые production/demo, затем Chromium integration в изолированной БД. Не менять production backend.
2. **Оргструктура:** схема/карточки/связи, корректный поиск (выполнено в ветке), горизонтальный canvas, таблица, мобильное отображение, CRUD только по разрешениям.
3. **Штатка:** 4 состояния референса, переключение табов, вакансия/изменение/версии, таблицы и мобильные карточки, фильтры, права.
4. **Карточка сотрудника:** 8 вкладок, поля, section toggles, scroll только по оси X у вкладок, mock/production separation.
5. **Общие стили:** единственная система Golos Text, semantic colors, кнопки/таблицы/селекты, sidebar, дроверы и dark theme.
6. **Остальные страницы:** документы, действия, резерв/обучение, табель, графики отпусков, отчеты, настройки.
7. **Финал:** screenshots side-by-side по доступным исходным макетам и список расхождений, Chromium desktop/tablet/mobile, CI PASS, preview на Vercel, затем согласованный merge `main`.

## Приемочные критерии

- Ни одного пустого обработчика у пользовательских кнопок. Для отсутствующего backend-контракта — явно недоступная функция с корректным сообщением, а не ложный успех.
- `document.documentElement.scrollWidth <= innerWidth + 1` на 375/768/1280/1440, но изолированный horizontal scroll внутри табов/таблиц/схемы допустим; нежелательного вертикального scrollbar внутри вкладок нет.
- Все четыре вкладки `OrgStaffingNav` открываются напрямую и при перезагрузке (organization, staffing, vacancies, changes).
- Sidebar раскрывается/сворачивается и не обрывается по высоте; поиск из topbar и внутри разделов ведет к реальным данным.
- Ни одной подмены реальных данных демонстрационными за пределами `VITE_DEMO_MODE`; соблюдаются tenant/company/department scopes, revisions и draft/approved запреты.
- `npm run typecheck`, `npm run build`, `npm run build:demo`, design tests, write/read-only E2E; browser pass только после действительного прохождения, а не наличия тестовых файлов.
- Статус `1:1` возможен только после повторного открытия исходных скриншотов и визуального подтверждения; текущий барьер — недоступные байты ZIP.
