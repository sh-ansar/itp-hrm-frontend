# B02 — Hierarchy presentation

The organization page provides a bounded paginated view (25 departments/page), parent labels, and indentation where a parent is present on the current page. It does **not** claim a complete tree. Hidden or off-page ancestors are labeled without revealing names or inheriting access. A cyclic legacy graph is guarded against infinite recursion. Depth is capped for legibility.

No company/department write permissions are activated. Full tree, cycle prevention on writes and customer-approved hierarchy behavior remain pending.
