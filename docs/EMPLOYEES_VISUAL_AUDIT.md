# Сотрудники — сверка фронтенда с прототипом

Эталон: пользовательский архив `Зип.zip`, папка `Employees Page — копия`, особенно
`Desktop_Employees_Реестр сотрудников_Без группировки.png`,
`Desktop_Employees_Реестр сотрудников_Группировка по отделам.png`,
`Карточки сострудников/Desktop_Employees_Карточка сотрудника_Личные данные 1.png`,
`..._Организационные данные 1.png` и `..._Трудовые данные 1.png`.

## Область работы
- `src/views/EmployeesView.vue`: реестр, архив, поиск, фильтры, группировка, настройки колонок.
- `src/views/EmployeeDetailView.vue`: заголовок, анкетные поля, вкладки и кадровые записи.
- `src/components/EmployeeProfileSection.vue`: единая раскрывающаяся секция вкладок.
- `src/components/ui/BaseDataTable.vue`: изолированная горизонтальная прокрутка таблиц.
- `public/prototype-icons`: оригинальные SVG из `Иконки.zip`.
- Шапка и меню в `src/App.vue` общие для проекта. При параллельной работе менять согласованно.

## Проверяемые состояния
- Ширины 375, 768 и 1280 px: без горизонтальной прокрутки страницы.
- Группировка в реестре; открытие архива и возврат в реестр.
- Переход из строки в карточку; 8 вкладок; раскрытие/сворачивание секций.
- Выдача данных только согласно API и правам. Отсутствующие поля не заполнять вымышленными значениями.
- Сборка: `npm run build`; браузерная проверка: `C:\dev\itp-hrm\browser-check\comprehensive-smoke.cjs`.

## Остаточные отличия от макета (не считать завершёнными)
- Фото: в API ещё нет безопасной загрузки/получения. Визуально показано отсутствие фото.
- Перечень сотрудников: дата рождения, дата приёма и пол не гарантированы API списка; не выдавать детальные персональные данные широкой роли.
- Контракты, документы удостоверения личности, выплаты, графики и аудит: вкладки размечены, но источники данных не подключены.
- Дополнительные фильтры/шаблоны/экспорт требуют функционального контракта и проверок прав.
- Пиксельное совпадение со всеми состояниями нового ZIP ещё не подтверждено.

Не объединять фиктивные данные с реальной базой; не развёртывать без проверки доступа и интеграции.
